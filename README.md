# パスワード付きトレース教材

このリポジトリに入れるのは、`locked_site/` 内の暗号化済みHTMLだけです。問題文・コードの平文、PDF原本、共通パスワードはGitHubへアップロードしません。サイトはGitHub Pagesで公開できますが、パスワードなしでは内容を復号できません。

## 問題を追加する手順

1. 手元の `traces_20261010/` に `trace_011_問題名.html` のように新しい単一HTMLを追加する。
2. 手元で `python update_index.py` を実行して問題一覧を更新する。
3. 手元で `node export_locked_site.cjs` を実行する。最初の実行時に `site_password.txt` が作られる。以降は同じパスワードで暗号化される。
4. `locked_site/` の変更だけをGitHubにプッシュし、公開を選んだ後に **Actions → Publish trace apps → Run workflow** を実行する。

`site_password.txt` は `.gitignore` に登録済みです。共有先は授業担当者と情報処理部に限り、パスワードを別経路で伝えてください。パスワードを変更する場合はファイルの内容を変更し、再暗号化してください。長さ24文字以上の推測されにくいパスワードを使います。

## 公開時の注意

GitHub Pagesにはアクセス制御がないため、暗号化済みファイル自体は誰でも取得できます。強いパスワードでない場合、総当たりによって読まれる可能性があります。閲覧者が復号後の内容を保存・再配布することも防げません。暗号化やパスワードの配布は、著作物の利用許諾の代わりにはなりません。特に情報処理部への配布が授業目的の利用範囲に含まれるか、公開前に学校の著作権担当窓口へ確認してください。

公開先を設定する際は、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。公開ワークフローは手動起動のみです。
